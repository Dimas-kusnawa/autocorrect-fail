A program that writes one line to `/output/entry.txt` (82 characters, inside the 199-character gate): "Texted my wife 'bring home milk'. Autocorrect sent 'bring home Mike'. Who is Mike?" One wrong word — "Mike" for "milk" — turns a grocery run into a new person in the marriage, and the punch lands without any explanation. It reads as a real autocorrect slip, not a written joke.

## Run it

```sh
python3 main.py
```
